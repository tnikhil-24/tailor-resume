# 07 — Top Nav Bar

## What to build

Add a persistent top nav bar to the single-page app with two pill-style tabs: **Tailor** and **Tracker**. Clicking a tab shows the corresponding view `<div>` and hides the other. The Tracker tab can show a placeholder ("Coming soon") — no backend needed. This is pure frontend work in `index.html`, `style.css`, and `app.js`.

Active tab = green filled pill (`#2a9d5c`, white text). Inactive = plain text, no fill.

## Acceptance criteria

- [ ] Nav bar is visible at the top of the page at all times
- [ ] Tailor tab is active by default on page load
- [ ] Clicking Tracker tab hides the Tailor view and shows the Tracker view (placeholder content is fine)
- [ ] Clicking Tailor tab restores the Tailor view
- [ ] Active pill is green-filled; inactive is plain text
- [ ] Nav bar does not interfere with the existing sticky generate bar

## Blocked by

None — can start immediately
